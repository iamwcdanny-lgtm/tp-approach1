01 / Issue

Two issuance models for different issuance needs.

Choose an issuance model based on the asset, participation requirements and target market.

VATP CONTRACTCUSTODY

Permissioned RWA issuance

For RWA that requires investor eligibility, wallet permissions and product-specific transfer and redemption rules.

  • Investor eligibility
  • Transfer rules
  • Subscription & redemption
DEFI CONTRACT

Permissionless RWA issuance

Issue from an eligible underlying asset or from an existing RWA token. Permissionless RWA tokens can be freely transferred on-chain and connected to DeFi.

  • Underlying asset
  • Existing RWA token
  • Connect to DeFi

03 / Connect

Extend RWA liquidity through DeFi.

Depending on the project’s starting point, issue directly from an underlying asset or extend an existing RWA token into DeFi financing.

Path 01 · Direct issuance

Issue directly from an underlying asset

For projects without an existing token. Design the token and contract structure for DeFi collateral and lending.

START Underlying asset
ISSUE Permissionless RWA token
CONNECT Collateral & lending

Path 02 · Token extension

Extend liquidity for an existing token

For eligible existing RWA tokens. Following custody and reserve verification, issue a mirror token for use in DeFi collateral and lending.

START Existing RWA token
VERIFY Custody & reserve verification
ISSUE Mirror token issuance
USE DeFi collateral & lending

Availability, collateral requirements and lending terms depend on project eligibility, jurisdiction and partner approval.
